# Editorial roadmap

## Publication gate
Every page must have a distinct intent, a real example, a practical exercise where appropriate, useful internal links, a unique title/description, and a source check for factual claims. Pages that only swap audience labels or keywords are rejected.

## First published batch
The initial build contains core pages, six course pages, and twelve distinct guide pages. These are **IMPLEMENTED** locally, not published or indexed until a verified production deployment.

## Next batches
1. Add 18 deeply researched communication and practice guides, with unique examples and manual editorial review.
2. Add complete multi-lesson course sequences and genuinely useful companion PDFs.
3. Add 50 pages only after the cluster map, orphan report, duplicate-intent review, and external-link checks pass.
4. Expand in reviewed batches of 25–50; do not use automated mass publication.
