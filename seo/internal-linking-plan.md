# Internal linking plan

- Header links point to Books, Learning Hub, Courses, Guides, About, and Contact.
- Each guide links to the Guide hub, Learning Hub, and only the genuinely relevant book page.
- Each course links to the Learning Hub, Guides, and the relevant book page.
- Book pages link to the Learning Hub, not a purchase-only dead end.
- Build check fails local broken links. Add an orphan-page audit before any large content batch.
